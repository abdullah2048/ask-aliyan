# Ask Aliyan

A bromance-prank spin on the classic "will you be my Valentine" page, made for Aliyan.

- **No** flees the moment a cursor, finger, or keyboard focus gets near it — it teleports somewhere else inside the card and never actually registers a click. The caption roasts Aliyan specifically the longer it's dodged ("No has ghosted harder than Aliyan ghosts the group chat").
- **Yes** fires confetti and reveals an **Official Bromance Certificate**: duties (steal fries without asking, hype man on demand), validity ("until he borrows money again"), witnesses (the entire group chat).

## Open source credit

The confetti is powered by [canvas-confetti](https://github.com/catdad/canvas-confetti) by catdad (MIT licensed), loaded straight from cdnjs.

The genre itself — a self-dodging "No" button, a growing "Yes," a payoff on click — is directly inspired by [`saurabhnemade/will-you-be-my-valentine`](https://github.com/saurabhnemade/will-you-be-my-valentine). All the code, copy, and the certificate design on this page are original.

## Running it

It's a single static `index.html` with no build step. Open it directly, or serve it with GitHub Pages (Settings → Pages → Deploy from branch `main` / root).
